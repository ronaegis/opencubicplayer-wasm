Instructions

  • Use "Open a module from this computer" above, or drop a file on that box. The bytes are written to /music and show up in the on-canvas file selector.
  • Open the file from that selector. Playback controls are the desktop player's keys inside the canvas. F returns to the selector during playback. Esc returns to the selector in this browser build. Press F1 for help, then F1 or Esc to close it.
  • Audio CD and MusicBrainz lookups are not in this build. There is no service worker. Settings are stored in this browser. A save runs when you leave the page; the browser can still drop it if it closes the tab first.

How to host this page

Desktop browser: the player canvas is at least 640 pixels wide and there is no touch keyboard.

The Modland drive contacts the third-party host modland.com and downloads a module when you open it.
