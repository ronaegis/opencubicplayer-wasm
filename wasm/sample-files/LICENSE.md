These nine modules are the demo set. Each file is the unmodified Mod Archive upload and is served beside the page. None of them is packed into `ocp.wasm` or `ocp.data`.

The [Mod Archive Distribution license](https://modarchive.org/index.php?faq-licensing) (upload terms section 1.2) lets anyone redistribute the original, unmodified, unbundled file. It does not allow editing the file or compiling it into an application.

## Files from the old demo set that stay out

Attribution inside a file is not a license to republish it. These historical names are absent from this directory:

- Commercial game recordings: `01 Title Theme.spc` (Jim Power), `Impossamole.ay` (Gremlin Graphics, 1990), `Last_ninja.ym`, `Ocean_Loader_2.sid` (Martin Galway, Ocean, 1985), `POLICE4.ROL`.
- Stock test media: `file_example_MP3_2MG.mp3`, `file_example_OOG_1MG.ogg`, `file_example_WAV_1MG.wav`, `sample-4.flac`. A “free for testing” download page is not a grant to republish the bytes.
- `standard.bnk`, an AdLib Visual Composer instrument bank, with no written grant in this tree.
- `2ND_PM.S3M`. Purple Motion’s “UnreaL ][ / PM” is on Mod Archive as [212083](https://modarchive.org/module.php?212083) under the Distribution license, but the copy previously stored here has a different MD5 (`8a19a2cebf0e7ae3dcae38a6633bebb6`, not `66af9167fcf28a6ecb3e2e25fa11a833`).
- `zabutom-broken words.xm` and `solskogens_pi.hvl`. Author text is in the files. No Mod Archive license page was found for those exact uploads.

Visitors can still open their own files from the page. The control writes those bytes into the player’s `/music` directory.
