# Demo audio

This directory ships no music files.

The previous demo set included commercial game recordings and other tracks with no redistribution grant in this tree (Ocean Loader 2, Last Ninja, Impossamole, a Police Quest-style ROL, an SPC title theme, stock `file_example_*` media, and several scene modules). Those files are not part of this release.

`standard.bnk` was removed for the same reason: this tree had no written grant for that AdLib bank.

Visitors open their own files from the page. The control writes the bytes into the player's `/music` directory.
